# Source access and independent implementation

The completed research records map the paper's v1 mathematical statements to P1 and P2. P3 reads those recorded reports/manifests and packages the results; it does not represent a new external review. Paper: [arXiv HTML](https://arxiv.org/html/2610.26797v1), [abstract](https://arxiv.org/abs/2610.26797v1).

P1/P2 were independently implemented from the mathematical assumptions/formulas. No author code was opened, copied or relicensed. The paper's HTML/PDF and author code are not redistributed. Historical source-access notes are retained byte-for-byte inside the evidence and are available after [restoration](EVIDENCE.md).

The independently authored project work uses [MIT](../LICENSE); the source paper and dependencies retain their own rights ([NOTICE](../NOTICE)). Implementation, numerical checks and visual inspection are AI-assisted. No human independent review or external-machine reproduction is asserted.
