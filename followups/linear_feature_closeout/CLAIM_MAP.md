## 결과를 읽는 범위

P1/P2는 Gaussian 고정 선형 표현의 기대 risk를 실제 반복 학습과 대조한 재현이다. Transformer 부록은 실제 고정 feature 위의 선형 readout을 실행했고, G는 해당 유한 train 표본에서 전달된 오류 에너지를 실제 eval teacher-error 에너지로 나눈 값이다. G_high≈1은 span 성분을 옮기는 OLS 성질의 검산이다.

F2/F2R의 중단, test prefix128 노출, P1의 사후 진단 교정, source bundle과 공개 manifest의 구분은 [보존·접근 이력](PROVENANCE_AND_HISTORY.md)에 모았다. 원 동일오류크기 H1 본실험·final, H2 비선형 학생, H3 학습되는 표현은 NOT_RUN이다. 자연 teacher 오류·생성형 KD·일반 압축 우월성·원문 전체 실험은 완료 범위 밖이다.
